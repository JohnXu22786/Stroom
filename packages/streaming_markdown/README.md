# Stroom streaming Markdown dependencies

These packages are Stroom-owned source copies of `markdown` 7.3.1 (Dart project authors, BSD-style license) and `markdown_widget` 2.3.2+8 (MIT license). Their original package licenses and source notices are retained beside each package.

The local `markdown` extension reports source line ranges for top-level parsed blocks. The local `markdown_widget` extension keeps rendered widgets for sealed blocks and reparses the active block only within a bounded live-preview budget. During uninterrupted streaming, the active tail switches to a bounded preview after 16 KiB or 64 appends in the current text chunk; ordinary text remains source-preserving, while excerpts containing strong emphasis or display math use the Markdown parser so those constructs do not show literal markers. The append budget is preserved when the UI reattaches to a stream, so its preview behavior does not depend on page lifecycle. An initial or reattached snapshot over 16 KiB is previewed without parsing unless it contains strong emphasis or display math. If streamed content changes document-wide link or footnote state, the whole live section also switches to this bounded preview so sealed widgets cannot keep stale references. The finalized message returns to the canonical full Markdown renderer. Incremental callers provide a lazy full-section callback for these rare invalidations.

The app selects these local copies through `dependency_overrides` in the root `pubspec.yaml`; the global Pub cache is never modified. Keep the package versions aligned with the root dependency constraints and preserve the accompanying license files when updating either source copy.
