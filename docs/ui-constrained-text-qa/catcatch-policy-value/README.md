# CatCatch selected policy label

The screenshot and playable preview show the production `CatCatchPolicyMenu` selected-value control at 320 × 640 CSS pixels, device pixel ratio 1, German (`de-DE`), Material 3 light theme, and normal 1× text scale. The control is placed in a 200 dp finite-width slot to capture its genuinely clipped state. The localized selected value is `Automatisch mit Bestätigung`; it is revealed horizontally. No synthetic text or provider request is used.

- [320 × 640 screenshot](catcatch-policy-de-320x640-1x-light.png)
- [Playable clipped-label preview](catcatch-policy-value-motion-320x640.webm)

Both CatCatch policy fields use this shared widget, so output and resource-selection selected values receive the same one-line behavior. In the block settings sheet, the field column is constrained by the available viewport width.
