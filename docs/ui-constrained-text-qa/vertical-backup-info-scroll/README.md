# Backup info dialog scroll

Production `BackupRestorePage` info dialog captures at 320 × 640 logical
pixels, de-DE, light theme, with 1× and 2.5× text scales. The scaled capture
shows the end of the detail text after scrolling; the “Got it” action stays
visible. No control is focused, the software keyboard is closed, and no backup,
restore, persistence, account data, or network request is used.
