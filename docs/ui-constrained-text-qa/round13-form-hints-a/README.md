The native model and JSON fields remain editable controls. The capture test measures the rendered hint slots, verifies the fitting model-ID hint remains stationary, and confirms the localized JSON hint is clipped. The browser edit capture demonstrates the production JSON field accepts text and hides its hint while nonempty. Flutter test captures for the Simple Model Configuration and Anki production pages are generated by `tests/qa/round11_static_input_hints_capture_test.dart`; the focused JSON widget captures are taken 1.25 seconds after clearing the field, so the German hint is visible while clipped, in both light and dark themes. The Anki test also enters `Mathe Physik` into the native tags field and verifies the value.

## Rename dialog close regression

The Conversations and Topic Selection rename fields keep their native text editing and measured hint behavior. Their controllers are owned by the page state so focus-loss updates remain valid while the dialog closes. Regression coverage submits a focused rename in both production pages: `tests/widgets/conversations_test.dart` and `tests/pages/settings/topic_selection_page_test.dart`.
