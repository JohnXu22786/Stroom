# Backup restore result dialog

These are Chromium screenshots of the production `BackupRestoreRestartDialog`
widget in a local Flutter Web build. The fixture uses translated German
skipped-category and restore-result copy long enough to require scrolling. It
performs no backup or restore and uses no account data or network request.

- Viewport: 320 × 640 CSS pixels, DPR 1
- Locale and theme: de-DE, Material 3 light
- Text scale: 1×
- Focus and keyboard: no focused control; software keyboard closed
- Screens: initial scroll position and scrolled result content; both actions
  remain visible

Capture command: `python tools/qa/capture_vertical_result_dialog_scroll.py`
