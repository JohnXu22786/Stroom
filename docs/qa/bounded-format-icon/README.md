# Text storage format icon

The [actual Text Storage page capture](text_storage_page-mmd-320x640-1x-light.png) is from a release Flutter web build in Chromium at a logical 320 × 640 viewport, device pixel ratio 1, and normal text scale. It renders `TextStoragePage` through `FileManagerView` and its production `fileIconBuilder`; the `Note.mmd` fixture appears in the real file grid.

The current regression captures use the production `TextStoragePage` and a local HTML record named `A`, in French (`fr-FR`) at 320 × 640 CSS pixels and device scale factor 1. The [1× light capture](text-storage-html-320x640-1x-light.png) shows the fitting `HTML` label in its original 44 dp square. The [4× light](text-storage-html-320x640-4x-light.png) and [4× dark](text-storage-html-320x640-4x-dark.png) captures show fully visible scaled glyphs inside the taller badge while the label remains horizontally clipped under reduced motion. The full `A.html` name and action stay beside the badge.

The [14-second WebM preview](text-storage-html-4x-dark-reveal.webm) starts with the initial hold, shows the label moving through both actual text endpoints and returning, and records the 4× dark-theme state. The 1× fitting and 4× enlarged screenshots use reduced motion; at 4× the cropped beginning remains visible without the ellipsis hiding the glyph. The WebM uses normal motion. The fixture is local and makes no provider or network requests. Rebuild the release harness and all current artifacts with `python3 tool/qa/capture_text_storage_format_badge.py`.

The [MMD fitting-label capture](mmd-label-light-320x640.png) isolates the production 44 dp icon and `ConstrainedText` at 1× text scale; the complete label stays centered and stationary. The [YAML reveal preview](yaml-reveal-2x-dark.gif) ([WebM](yaml-reveal-preview.webm)) shows the full value moving at 2× text scale in dark theme. The [start frame](yaml-reveal-start.png) and [moving frame](yaml-reveal-moving.png) are extracted from the Chromium recording.

The widget regression verifies the 44 dp baseline and measured badge height at 4×, checks that the filename and action do not overlap the expanded badge, and covers English/German locales, light/dark themes, and 1×/2×/4× scales. It also checks that reduced motion clips a visible starting glyph instead of ellipsizing away the entire label. A separate motion test keeps the prior 2× YAML reveal behavior. The supported format set is `txt`, `md`, `mmd`, `html`, `json`, `xml`, `csv`, `yaml`, `yml`, `toml`, `ini`, `cfg`, `log`, and `env`.
