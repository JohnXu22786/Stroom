# Stroom 0.7 Development Plan

`v0.7` is the development and integration branch for the Stroom 0.7 series. This plan defines the conversation UI work currently assigned to that version line. Track individual tasks through the related issues and pull requests.

## Goal

Replace each conversation message's content area with a Stroom message interface adapted from DSH's web UI, preserve Stroom's existing behavior, and provide a consistent experience on all supported platforms.

## Scope

- Add WebView integration for every supported platform so the web message area can work with the existing Flutter interface.
- Replace only the message content area, focusing on Markdown and multi-step tool call information.
- Keep the input composer, top area, other interface surfaces, and full-screen content pages in Flutter.
- Remove the like and dislike buttons. Keep DSH's other message actions and add Stroom's existing message actions and functionality. Icons and layout may be adapted to Stroom's interface.
- Reasoning-related dialogs may continue to use Stroom's existing implementation.
- Support the current conversation data after an explicit migration. The migration flow handles data from older versions; this work does not add a second compatibility layer for pre-migration data.

## Acceptance Criteria

- The message web UI loads and displays correctly on every supported platform.
- Markdown, tool call steps, and Stroom message actions work in a conversation.
- The input composer, top area, other non-conversation surfaces, and full-screen content remain rendered by Flutter.
- The message actions do not include like or dislike, and the other agreed actions retain their functionality.
