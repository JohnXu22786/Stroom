## Security and connector evidence

- Deterministic backup tests verify credential-field redaction and secure-reference handling. Exported backups do not contain platform keystore values; restoring in a different device or browser origin may require credentials to be entered again.
- Credential deletion removes the local secure value only when no account record still owns that reference. The connector account editor has no provider-side logout or OAuth-grant revocation action. Connector refresh is implementation-specific and has not been exercised against a live OAuth account.
- Connector exceptions and route diagnostics avoid exposing credentials or request content. `AppLogService` writes the caller-supplied message unchanged and does not provide general-purpose secret scrubbing; custom log messages must not contain keys, tokens, or private prompt content.
- Unknown quota remains unknown in routing and UI. The frozen matrix identifies the connectors with source-backed account-quota endpoints; for other connectors, request usage is not a provider balance. Model catalogs and settings do not verify account entitlement.
- AI Studio bridge contract tests pass, but no signed-in AI Studio WebView session was available. The bridge is bound to an in-app `aistudio.google.com` page, limits outbound requests to the Generative Language API request shapes documented in [LLM 账号与模型组使用说明](../llm-accounts-and-model-groups.md), and does not read or copy browser cookies or tokens. The connector is not exposed in the current ChatAdapter model selector.
- No live provider credentials or user-device runtimes were used. OAuth login/refresh/disconnect, live provider requests and quota, model entitlement, secure-storage behavior on mobile/desktop/Web, and cross-platform connector behavior remain unverified.
