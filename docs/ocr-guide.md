# OCR 文字识别

## 配置

在供应商配置中添加或编辑 **OCR** 类型的供应商，填写完整的 API 地址和 API Key，再添加模型并填写服务商给出的模型 ID。当前 OCR 请求使用 OpenAI 兼容的视觉 Chat Completions 格式；模型必须支持图片输入。地址应包含服务商要求的完整路径，例如 `/v1/chat/completions`。

Temperature、Top P 和最大 Token 数默认不发送。只在服务商支持且确有需要时启用它们。服务商特有参数可以放入模型的“自定义参数”；参数名和值必须符合服务商接口。不要把 API Key 放进模型 ID 或自定义参数。

打开首页的 **OCR / 文字识别**，选择已配置的模型，再从相册或相机导入图片。标准画质会把系统选取的图片限制到最长边 2048 像素、JPEG 质量 90；**原图 / 高细节**会请求保留原始尺寸和质量，可能明显增加上传数据量。OCR 页的请求上限默认为 20 MiB，可在页面上调整。图片经过编辑后会以实际输出内容提交。

识别指令可在 OCR 页的指令管理中维护；选中的指令会作为额外的用户指令应用于 OCR 请求。未选择指令时不会附加用户自定义指令，但请求仍包含默认 OCR 系统提示词。OCR 任务流块使用保存的 OCR 供应商和模型配置，并将图片转换为识别文本供后续步骤使用。

## 排查问题

- **401 / 403**：确认 API Key、服务商账号权限以及端点所要求的认证方式。
- **404**：检查 API 地址是否包含正确的版本和 Chat Completions 路径。
- **请求过大或 413**：如果页面提示本地请求体超过上限，可减少图片负载，或酌情提高 OCR 页的 JSON 请求上限；如果服务商返回 413，应降低图片质量或数量，并确认服务商的请求限制。图片会编码进 JSON，因此请求体会大于原始图片文件。
- **参数错误**：先关闭可选的 Temperature、Top P、最大 Token 数和自定义参数，再按服务商文档逐项启用。
- **格式错误**：重新导入图片，或先转换为 PNG、JPEG、WebP。HEIC、SVG 和 TIFF 当前不支持。
- **超时、限流或服务错误**：检查网络和服务商状态，确认模型可用后，在后台任务中重试失败任务。

## 限制

OCR 由配置的在线视觉模型完成，不提供离线识别。可识别内容、布局保留、手写字效果和语言支持取决于服务商及模型；请在保存前校对结果。图片尺寸、请求大小上限、服务商额度和模型上下文限制都会影响一次请求可处理的内容。项目中的自动化测试使用可控的模拟响应，不代表任何在线模型的准确率或速度。
