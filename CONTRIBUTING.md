# Contributing to Stroom

Stroom is a Flutter application. Before changing its interface, read the [UI guidelines](docs/ui-guidelines.md). Search `lib/` and `packages/streaming_markdown/` for the existing component and all call sites, reuse shared theme/widgets where appropriate, and update every affected screen. Keep the external math component outside the change scope.

Check the affected light/dark and responsive states, run the relevant project checks, and describe the impacted screens, reuse/search, validation, and representative state in your pull request. Add a genuine screenshot when it helps reviewers understand the change. See the [popup/dropdown inventory](docs/ui-popup-dropdown-inventory.md) for current menu call sites.
